Publish directly from this page

A one-time setup lets the editor commit straight to your GitHub repo — from any device, no git needed. The token is stored only in this browser.

  1. Open github.com → Settings → Fine-grained tokens → Generate
  2. Repository access: Only select repositories → choose tobyn-smith/me
  3. Permissions → Repository → Contents: Read and write (nothing else)
  4. Generate, copy the token, paste it below
Your token is encrypted with this passcode (AES-GCM) before it's stored, so it can't be read from this browser without it. There's no recovery — forget it and you just generate a new token.
